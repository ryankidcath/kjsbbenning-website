# Handoff: Project Manager → Growth/Marketing

## From
Project Manager

## To
Growth/Marketing

## Context

CEO meminta tambahan satu halaman artikel SEO baru untuk website **kjsbbenning-website**. Fokus berbeda dari artikel verifikasi PSU sebelumnya: kali ini menonjolkan kolaborasi dengan **BKAD** (Badan Keuangan dan Aset Daerah) dan **DPKPP** Kabupaten Cirebon.

**Target pembaca:** Dinas dan badan lain di pemda kabupaten Cirebon (bukan developer perumahan).

**Contoh pekerjaan dengan BKAD:**
- Pengukuran tanah aset pemda berupa jalan kabupaten
- Pengukuran, inventaris, dan identifikasi
- Menerbitkan Peta Bidang Tanah (PBT)
- Membantu mengawal pembuatan sertifikat di BPN

## Objective

Tulis **naskah artikel SEO lengkap** untuk halaman baru yang akan diimplementasikan oleh Frontend Engineer. Naskah harus siap dipakai langsung (copy-paste ke komponen).

## Constraints

- Satu halaman (bukan blog section)
- Target pembaca: BKAD, DPKPP, dinas/badan lain di pemda kabupaten Cirebon
- Integrasi keyword secara natural (tidak keyword stuffing)
- Alur kerja: pengukuran → inventaris → PBT → sertifikat BPN
- Boleh menyebut contoh proyek dengan discretion bila sensitif

## Deliverables

1. **Judul & Meta**
   - H1 (judul utama halaman)
   - Meta title (≈55–60 karakter)
   - Meta description (≈150–160 karakter)

2. **Konten Body**
   - Kolaborasi BKAD + DPKPP
   - Alur kerja: pengukuran aset pemda (jalan kabupaten) → inventaris → PBT → sertifikat BPN
   - Struktur H2/H3 yang logis
   - Integrasi keyword: "pengukuran aset pemda", "inventarisasi tanah jalan kabupaten", "BKAD Cirebon", "PBT aset daerah", "sertifikasi tanah pemda", "pengukuran jalan kabupaten"
   - CTA ke WhatsApp/konsultasi
   - (Opsional) Angka pengalaman / contoh proyek bila relevan

3. **Format Output**
   - Dokumen Markdown atau plain text dengan markup jelas (H1, H2, H3, paragraf)
   - Siap diserahkan ke Frontend untuk implementasi

## Dependencies

- Pengetahuan domain: BKAD, DPKPP, inventaris aset, PBT, sertifikat BPN
- Referensi tone & panjang: halaman verifikasi-psu-dpkpp-cirebon, survey-lahan-perumahan-cirebon

## Open Questions

- Apakah perlu link silang ke halaman verifikasi-psu-dpkpp-cirebon? (Eskalasi ke CEO jika perlu)
- Apakah ada proyek spesifik dengan BKAD yang boleh disebutkan? (Eskalasi ke CEO jika perlu)

## Done When

- Naskah lengkap dengan H1, meta, body, dan CTA
- Keyword target terintegrasi secara natural
- Alur kerja (pengukuran → inventaris → PBT → sertifikat) tercakup
- Siap diserahkan ke Frontend Engineer
